
# ServiceNow ITSM Homelab

## Project Overview

This project is a hands-on ServiceNow IT Service Management (ITSM) homelab designed to develop practical experience with enterprise IT support workflows, ticket management, incident resolution, and service operations.

The lab will use a ServiceNow Personal Developer Instance (PDI), subject to availability, to simulate common IT help desk scenarios and document the configuration, troubleshooting process, and outcomes of each exercise.

## Objectives

- Develop practical experience navigating the ServiceNow platform.
- Learn incident management and ticket lifecycle workflows.
- Practice ticket prioritization, categorization, assignment, and resolution.
- Understand assignment groups, escalation, and service-level agreements (SLAs).
- Explore knowledge management and service request workflows.
- Document troubleshooting steps and technical findings.
- Build a portfolio demonstrating IT support and ITSM skills.
